二、国内外研究现状
□ CLI 与 GUI 混合能力交互（Hybrid-Modality Interaction）仍然是一个极具挑战性的课题
■ 长程视觉感知开销高
高分辨率截图随交互步数持续累积，视觉 token 与 KV 缓存（KV Cache）线性膨胀，推理延迟与显存开销制约长程任务的执行。
■ 任务范式与能力度量失配
现有基准将文本与视觉割裂评测，任务可在单一能力内完成；仅依据最终结果判分，通过率虚低 10–20 个百分点，并不能衡量模型在这个场景真正解决问题的能力。
■ 混合行为模式难以习得
图形界面缺少天然的可验证奖励，混合训练环境与数据稀缺；仅依据结果的奖励易被违规取巧（Reward Hacking）利用（上图），自主编排与自我验证行为难以习得。
核心问题：如何使智能体获取在 CLI 与 GUI 间高效感知、合理编排能力，并是通用智能体获得真正可以转化成实际生产力的能力？
